## 🚧 Active Projects

### 📡 ESP32-C5 Weather Station
Multi-unit deployment across labs at **BPSUML**.  
Sensors report **humidity · temperature · barometric pressure** via HTTPS GET to a hosted server.  
FreeRTOS tasks handle non-blocking HTTP, I2C LCD display, and MAC-based WiFi whitelisting.

```
Labs: K46 · B · C · D · E
Board: ESP32-C5  |  Sensor: MHB-382SD  |  Display: I2C LCD
```

### 🌐 BPSUML Web Platform
Internal dashboard built with **Laravel + Blade**.  
Features a dark-mode landing page with GSAP ScrollTrigger 3D scroll animations,  
Chart.js visualizations (monthly volume, doughnut, stacked area, SLA progress bars),  
and a correspondence management system backed by a relational DB.
