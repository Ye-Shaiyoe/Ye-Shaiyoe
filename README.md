## Cara Menjalankan (Local)

1. Clone repo

```bash
git clone https://github.com/Ye-Shaiyoe/Ye-Shaiyoe.git
cd Ye-Shaiyoe
```

2. Buka file `index.html` di browsermu atau jalankan dev server sederhana:

```bash
# dengan Python 3
python -m http.server 8000
# buka http://localhost:8000
```

3. Atau gunakan tooling yang ada di proyek (npm, vite, dsb.) jika tersedia:

```bash
# contoh (opsional) jika menggunakan npm
npm install
npm run dev
```

## Struktur Direktori (Contoh)

- assets/        — gambar, ikon, dan media
- css/           — stylesheet
